2.2 定价模型（本文的"模型"部分，可在答辩现场黑板推导）

设新股内在价值 V 不可直接观测，上市首日市场由两类投资者构成：

  • 有锚投资者（机构）：能形成估值判断 V̂ = V + ε，估值误差方差与锚强度 a ∈ [0,1] 反向相关（Var(ε) = σ²/a）。在 CARA 效用与正态信念下，其股数需求为 DM = w(V̂ − P)，其中 w = a / (γσ²)，γ 为风险厌恶系数。锚越弱，w 越小；a → 0 时机构"集体沉默"，不报价、不纠偏。
  • 无锚投资者（打新资金与短线承接资金）：不以现金流定价，而以叙事定价，信念为 V + δ（δ > 0 为叙事溢价），需求 DN = η(V + δ − P)，η ≈ M/V 由入场资金规模 M 决定。
  • 供给：上市初期可交易筹码（流通容量）F。
(1)w(V + ε − P) + η(V + δ − P) = F 市场出清条件：两类投资者需求之和等于流通容量。
(2)E[P*] − V = θ · δ − F / (w + η)，其中 θ = η / (w + η) 求解 (1) 并取期望得到首日溢价分解式：溢价 = 无锚资金的定价权份额 θ × 叙事溢价 δ − 容量折价项。θ 即"定价权归属"的连续度量。

由模型直接导出的三个命题

  1. 命题 1（锚效应）：∂θ/∂a < 0 ⟹ ∂(溢价)/∂a < 0。锚强度越高，定价权越多地留在有锚机构手中，首日溢价越低、后续回撤越小。
  2. 命题 2（容量效应）：∂(溢价)/∂F = −1/(w + η) < 0。流通容量越小，同等资金推动下的价格偏离越大。战略配售锁定与网下限售正是压低 F 的制度渠道——"定价权—背书权分离"在此作为容量渠道的制度解释进入链条。
  3. 命题 3（交互，本文最具辨识度的一条）：∂²(溢价)/∂a∂F = w′(a)/(w + η)² > 0。容量对价格偏离的影响随锚强度增强而衰减；等价表述：小容量之所以危险，是因为它常与锚缺位同时出现；有锚的大市值新股即便流通盘不大，价格也不会脱轨。该命题对应回归中的交互项 Anchor × lnFloat，是把"双案例对照"升级为"可证伪规律"的关键。

纠偏阶段（解释暴跌，连接第四部分）

设 T 期后基本面信息（季报、订单、竞争格局）公开，估值误差方差下降、w 上升，价格向 V 收敛。可得：收敛期的纠偏成本（最大回撤）与首日溢价同号同阶，而收敛速度 T* 随锚强度递增（有锚者靠财报即可完成校准，无锚者必须靠交易试错完成校准）。这解释了宇树"一个月腰斩"与长鑫"稳步上行"的差别，并给出第三个被解释变量。

# 科创板新股定价锚横截面检验 —— 主回归骨架
import pandas as pd, numpy as np, statsmodels.formula.api as smf

df = pd.read_excel("star_ipo_panel.xlsx")        # Wind 导出后清洗好的横截面

# ---- 1. 锚强度指数（三分项）----
df["A1"] = ((df.np_parent_pre > 0) & (df.ded_profit_pre > 0)).astype(int)
df["A2"] = ((df.ipo_pe > 0) & (df.ipo_pe / df.ind_pe <= 2)).astype(int)
df["A3"] = (df.west_instnum_30d >= 3).astype(int)

# MDD60 由日行情序列另行计算：max((peak - trough_after_peak) / peak) over 60 日
