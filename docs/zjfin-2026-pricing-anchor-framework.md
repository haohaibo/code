## 2. 理论架构：锚—容量二维模型

### 2.1 机制链条（图 1，全文只出现一次）

```
制度起点：第五套标准扩容 + 战略配售锁定
        ├── 维度 A：锚强度 a（能不能算清）
        └── 维度 F：流通容量 F（谁来承接）
                    ↓
          定价权归属 θ：有锚机构 ⟷ 无锚打新/短线资金
                    ↓
          价格形成 P* = V + θ·δ − F/(w+η)
                    ↓
          价格发现质量：收敛速度 T*、偏离深度、纠偏成本
                    ↓
    制度出口：新股定价锚制度（锚披露 · 锚供给 · 锚—容量匹配）
```

### 2.2 定价模型（本文的"模型"，可现场黑板推导）

新股内在价值 V 不可观测，首日市场由两类投资者构成：

1. **有锚投资者（机构）**：估值判断 V̂ = V + ε，Var(ε) = σ²/a，a ∈ [0,1] 为锚强度。CARA-正态下股数需求 D_M = w(V̂ − P)，其中 **w = a/(γσ²)**。锚越弱 w 越小；a→0 时机构"集体沉默"，不报价、不纠偏。
2. **无锚投资者（打新与短线承接资金）**：以叙事定价，信念 V + δ（δ>0 为叙事溢价），需求 D_N = η(V + δ − P)，η ≈ M/V 由入场资金规模 M 决定。
3. **供给**：上市初期可交易筹码（流通容量）F。

**式(1) 市场出清**：w(V + ε − P) + η(V + δ − P) = F

**式(2) 首日溢价分解**：E[P*] − V = **θ·δ − F/(w + η)**，其中 **θ = η/(w + η)**（无锚资金的定价权份额）

#### 三个命题
- **命题 1（锚效应）**：∂θ/∂a < 0 ⟹ ∂溢价/∂a < 0。锚越强，定价权越多留在机构手中，首日溢价越低、后续回撤越小。
- **命题 2（容量效应）**：∂溢价/∂F = −1/(w + η) < 0。流通容量越小，同等资金推动下偏离越大。战配锁定与网下限售正是压低 F 的制度渠道——"定价权—背书权分离"在此作为容量渠道的制度解释进入链条。
- **命题 3（交互，本文最具辨识度）**：∂²溢价/∂a∂F = w′(a)/(w + η)² > 0。**容量对偏离的影响随锚强度增强而衰减**；通俗表述：*小容量之所以危险，是因为它常与锚缺位同时出现；有锚的新股即便流通盘不大，价格也不会脱轨*。对应回归交互项 `Anchor × lnFloat`，把"双案例对照"升级为"可证伪规律"。

#### 纠偏阶段（解释暴跌，连接第四部分）
T 期后基本面信息公开，估值误差方差下降、w 上升，价格向 V 收敛。可得：**纠偏成本（最大回撤）与首日溢价同号同阶**，**收敛速度 T\* 随锚强度递增**（有锚者靠财报校准，无锚者只能靠交易试错校准）。这解释宇树"一月腰斩"与长鑫"稳步上行"，并给出第三个被解释变量。

### 2.3 双案例的象限定位（图 2）
横轴 lnFloat、纵轴 Anchor 的四象限：
- **象限 Ⅰ 无锚 × 小容量**：定价权完全下移，高溢价、高换手、高纠偏成本 →（宇树科技：流通盘 7.44%，锚三分项全空）
- 象限 Ⅱ 有锚 × 小容量：偏离可控
- 象限 Ⅲ 无锚 × 大容量：溢价被稀释
- **象限 Ⅳ 有锚 × 大容量**：一日完成价格发现 →（长鑫科技：巨额流通市值，周期切换后动态锚清晰）
- 影子样本（主板低 PE、低流通盘个股）落在象限 Ⅰ 附近，证明规律跨板块复制

**为什么这个框架比 v4 更容易拿"创新性 25 分"**：①提出可度量的新构念（锚强度指数）；②把"战配悖论"降维为容量渠道，形成对既有文献的*收编*而非重复；③交互项命题**可证伪**且预测方向反直觉；④制度出口（锚披露）是监管文件尚未成文的具体方案。

### 4.3 回归设定

**式(3)**：`Y_i = α + β₁·Anchor_i + β₂·lnFloat_i + β₃·(Anchor_i × lnFloat_i) + Γ′X_i + λ_t + μ_j + ε_i`

Y 依次取 `UP1`、`CAR20`、`MDD60`；标准误在**申万二级行业层面聚类**；连续变量 1%/99% winsorize。每个 Y 报告三列：(1) 仅核心变量 + FE；(2) 加控制；(3) 加交互。

### 第四部分 问题与原因分析（约 4000 字，重心；A 主笔 / B 补数据 / C 润色）
**结构原则**：三层递进，每层只干一件事；段内固定"机理 → 证据"两步；证据一律先宇树后长鑫同框；每层末最多一张 3—5 行小表。

**层次一 现象与规律：这不是两只股票的故事（1300 字）**
- （一）镜像现象总览（350字）：双案例一段带过（不重复案例介绍的数据细节），加一句**影子案例**——低发行 PE、有稳定盈利的主板装备龙头，在高战配 + 低流通盘结构下同样出现极端行情并被实施异常交易监管，说明**现象与发行定价高低无关、与板块无关**。
- （二）**横截面证据（950字）**：描述统计与分组均值差（表3）→ 散点图（图3）→ 主回归（表4）→ 边际效应图（图5）→ 稳健性一段（表5）→ **案例残差回填（表6）**。渠道连接句必写："战配比例与首日流通市值的相关系数为 −0.XX，说明**抽离容量的主要制度渠道正是战略配售与网下限售**。"

**层次二 机理拆解（2200 字，四问，每问"点题句→机理→证据→回扣"）**
1. **（一）锚缺位：机构为什么集体沉默（700字，本节最重）**
   点题：没有锚，不是机构不想定价，是**无法在职业约束下给出一个能被复核的价格**。
   机理：估值误差方差随锚强度下降 → 机构需求曲线趋平 → 定价权份额 θ 上升（命题1）。
   证据：①宇树锚三分项全空 + 机构覆盖稀少、**目标价倒挂**；②**反向隐含推演**——由开盘价反推所隐含的远期净利润与复合增速，说明该价格对应的业绩要求超出行业现有龙头盈利水平；③PEG 远超常用阈值；④访谈嵌入（券商人士："对没有可比对象的资产，我们内部报价流程走不通"）。
   回扣：*锚缺位不是估值技术问题，是定价权归属问题。*
2. **（二）容量抽干：定价需要场地（500字）**
   点题：45 亿量级的流通容量，迎接的是数千亿量级的打新资金。
   机理：命题2 + 流动性溢价文献；战配锁定 → 背书权在手、交易功能归零 → **定价权—背书权分离**（在此命名，作为容量渠道的制度解释）。
   证据：拥挤度测算、中签率与流通市值的双案例倍差、横截面渠道相关系数。
   回扣：*容量决定了偏离能被推到多远。*
3. **（三）交互放大：无锚 × 小容量的乘数（500字）**
   点题：单独的小容量并不可怕，可怕的是小容量遇上没有锚。
   机理：命题3；**本节是相对既有"战配批判"文献的核心增量**。
   证据：边际效应图（图5）+ 象限图（图2）+ 反例个股（有盈利、有可比公司但流通盘同样很小、首月表现平稳的科创板个股 1—2 只）。
   回扣：*制度该修的不是容量一个旋钮，而是锚与容量的匹配关系。*
4. **（四）镜像反证：锚在场内，价格一天完成发现（500字）**
   点题：同样的长期资本，在一级市场定过价和在锁定名单里，结果完全不同。
   证据：长鑫"真假 PE"揭示 + 一级市场定价过程 + 首日高换手完成出清 + 绿鞋与长期承诺；**图 4 双瀑布图**（宇树：价值→+叙事→+稀缺，逐级脱离可计算区间；长鑫：盈利×倍数可计算）。
   回扣：*差别不在倍数高低，在锚的有无——从反面验证前三问。*

**层次三 根源与诊断（500 字）**
- **根源命名**：科创板已建立"谁能上市"的准入制度与"谁来背书"的配售制度，**尚未建立"如何算清"的定价锚制度**——锚的生产被完全交给市场自发行为，而在最需要锚的未盈利、无可比公司场景中，市场自发供给恰恰最少（**公共品供给不足**）。
- **竞争性解释排除（各一句数据）**：市场环境反证（上市当日大盘与科创50下跌，个股逆势暴涨，属孤立结构性事件）；发行定价反证（券商目标价区间显示**发行价并不贵，贵的是二级市场溢价**）；行业反证（控制行业 FE，且主板影子案例同象限复制）；业绩反证（长鑫处周期低谷却更稳）。
- **四处断裂清单（与第五部分建议一一对应）**：①**锚的披露断裂**（远期叙事无可检验的披露约束）；②**锚的供给断裂**（无锚资产无人校准、机构集体沉默）；③**锚—容量匹配断裂**（战配比例、锁定期与流通容量三者无底线约束）；④**缓冲断裂**（无绿鞋、无稳定盘、解禁无流量调节，纠偏只能靠暴跌完成）。
- 过渡句：四处断裂都是**机制设计问题而非市场道德问题**——"与其抑制炒新，不如为价格提供锚。"

### 第五部分 建议：新股定价锚制度三支柱（约 2000 字，C 执笔 A 审）

| 支柱 | 方案 | 操作细节 | 回应断点 | 实施层级 |
|---|---|---|---|---|
| **一 锚的披露** | **隐含业绩披露制度**：以非传统估值指标定价的发行人，须在发行文件披露"发行价所隐含的未来收入/利润要求"及关键假设 | 把反向隐含推演从研究工具变为发行要求；给出保守/中性/乐观三档敏感性区间与达成路径 | ① | 交易所业务指引 |
| **二 锚的供给** | **保荐机构锚定分析报告 + 研究覆盖前置**：须出具可比公司、订单/产能、单位经济性的量化对照；鼓励上市前研究覆盖与投价报告口径公开可核 | 可比公司选择标准与剔除理由须说明；无可比公司时须披露替代锚（订单簿、产能爬坡、单机价格曲线） | ② | 承销业务规范 / 行业自律 |
| **三 锚—容量匹配** | **"锚—容量匹配底线"**：锚强度低（未盈利且无可比上市公司）时收紧战配上限、提高初始流通容量下限、强制设置绿鞋 | 量化示例：流通市值／有效申购资金 ≥ 1%；低锚发行人战配比例上限由 20% 降至 12%；解禁流量调节（单月解禁市值超流通市值 50% 者分 3—6 个月释放） | ③④ | 发行承销业务指引 |

**规则锚（证明建议不是空中楼阁）**：上交所科创板发行承销业务指引已原则性要求"合理确定战略投资者家数和比例，**保障股票上市后必要的流动性**"。支柱三是把该条款**量化为可执行标准**，并把判定条件与锚强度挂钩——属参数化细化而非新设规则。

- **分主体配套（400字）**：发行人（锚的自建三原则）／承销与询价（报价问责、"四数孰低"约束的渐进放松方向）／监管（全周期价格发现治理、解禁预披露）／投资者（打新收益与接盘风险的对称性）。
- **实施优先级与成本收益（300字）**：短期＝发行人与保荐机构自律（零监管成本、可立即实施）；中期＝承销机制与自律规则；长期＝业务指引修订（治本）。"**短期靠自律、中期靠机制、长期靠规则。**"
- **收束段（150字）**：面向未盈利科技巨头上市潮的制度准备；紧迫性证据——监管已对同类个股实施异常交易监管，**制度补丁的窗口期就是现在**。

## 9. 答辩预案

官方结构：汇报展示 50%（全面性、逻辑性、**重点突出性**）+ 答辩展示 50%（清晰度、准确度、**适当度、沉稳度**）。

**汇报设计（前 50%）**：5 分钟讲稿＝"开场一句话 → 锚—容量框架一张图 → 模型一条公式 → 回归一张边际效应图 → 案例残差一句话 → 三支柱建议 → 金句收尾"。PPT ≤ 12 页：1 标题 + 1 框架图 + 1 模型 + 2 案例对照 + 2 实证（主表 + 边际效应图）+ 1 残差回填 + 2 建议 + 1 结语 + 1 尾页。**重点突出性靠"每页一个数字"实现。**

**沉稳度训练（后 50%）**：答不上来的标准动作——"这个问题我们讨论过，目前的证据是 X，但 Y 部分确实没有验证，这是我们下一步要补的。"**承认局限优于强行狡辩**；被质疑时不打断、听完再答、先结论后展开。三轮演练：完整讲 → 随机抽问打断 → 模拟刁难。

## 附录 B · 实证代码骨架（Python）

```python
# 科创板新股定价锚横截面检验 —— 主回归骨架
import pandas as pd, numpy as np, statsmodels.formula.api as smf

df = pd.read_excel("star_ipo_panel.xlsx")          # Wind 导出后清洗好的横截面

# 1. 锚强度指数（三分项）
df["A1"] = ((df.np_parent_pre > 0) & (df.ded_profit_pre > 0)).astype(int)
df["A2"] = ((df.ipo_pe > 0) & (df.ipo_pe / df.ind_pe <= 2)).astype(int)
df["A3"] = (df.west_instnum_30d >= 3).astype(int)
df["Anchor"] = df[["A1", "A2", "A3"]].sum(axis=1)

# 2. 被解释变量
df["UP1"]   = df.close_d1 / df.ipo_price - 1
df["CAR20"] = (df.close_d21 / df.close_d1 - 1) - (df.idx_d21 / df.idx_d1 - 1)
# MDD60 由日行情序列另算：60 日内 max((peak - trough_after_peak)/peak)

# 3. 容量、控制与去中心化交互
df["lnFloat"] = np.log(df.float_mktcap_d1)
df["lnSize"]  = np.log(df.ipo_amount)
df["lnPE"]    = np.log1p(df.ipo_pe.clip(lower=0))
df["A_c"]     = df.Anchor  - df.Anchor.mean()
df["F_c"]     = df.lnFloat - df.lnFloat.mean()
df["AxF"]     = df.A_c * df.F_c

# 4. winsorize 1%/99%
for v in ["UP1","CAR20","MDD60","lnFloat","lnSize","lnPE"]:
    lo, hi = df[v].quantile([.01, .99]); df[v] = df[v].clip(lo, hi)

# 5. 主回归：3 个被解释变量 × 3 个设定，行业聚类稳健标准误
base = "A_c + F_c"
ctrl = base + " + lnSize + lnPE + uw_rep + greenshoe + mktret20 + C(year) + C(ind_sw2)"
full = ctrl + " + AxF"
for y in ["UP1", "CAR20", "MDD60"]:
    for rhs in [base + " + C(year) + C(ind_sw2)", ctrl, full]:
        m = smf.ols(f"{y} ~ {rhs}", data=df).fit(
                cov_type="cluster", cov_kwds={"groups": df.ind_sw2})
        print(y, m.params[["A_c","F_c"]].round(4), m.nobs, round(m.rsquared_adj,3))
```
